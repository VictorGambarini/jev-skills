## Bounded installer refresh

`python3 install.py --hermes-root-only --check` previews a refresh of the
selected Hermes home only. Remove `--check` to refresh. This mode installs the
root plugins, skills, scripts and root CLI link, without editing config,
rewriting profile links, or installing into Claude Code, Codex or other agents.
It rejects uninstall and extra skills directories. Existing profiles already
linked to these shared root files will naturally see their updated contents;
this is not a promise of per-profile isolation. No running gateway is restarted,
and no routing mode is changed.
